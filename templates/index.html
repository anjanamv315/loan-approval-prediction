Evaluated Machine Learning Algorithms

Three diverse mathematical approaches were implemented and evaluated under identical conditions:

Logistic Regression Linear Model

Models the log-odds of the positive class (approval) as a linear combination of numerical and one-hot encoded variables transformed by the Sigmoid function.

  • Highly interpretable coefficients
  • Robust baseline for binary classification
  • Assumes linear decision boundary
Hyperparameters: max_iter=1000, L2 penalty
Decision Tree Non-Linear Rule Based

Recursively partitions the feature space based on Gini impurity reduction, producing an intuitive flowchart of binary decision rules.

  • Captures complex non-linear thresholds
  • Natural rule-based reasoning
  • Prone to overfitting on small datasets
Regularization: max_depth=4, min_samples_leaf=5
Random Forest Classifier Ensemble Model

An ensemble of 100 decorrelated decision trees trained on bootstrap resamples (bagging) with random feature subspaces, aggregating predictions via majority voting.

  • Significantly reduces tree variance & overfitting
  • Exceptional generalization performance
  • Consistent lead across 5-fold cross-validation
Ensemble: 100 Trees, max_depth=5
End-to-End System Architecture & Workflow
1. Dataset Validation

Loads 614 credit applicant records, inspects missing values, cleans Dependents ('3+' -> '3'), and verifies schema.

2. Leak-Free Pipelines

Imputation, Standard Scaling, and One-Hot Encoding are fitted only on training folds via scikit-learn ColumnTransformer.

3. CV Model Selection

Evaluates all 3 models with 5-fold Stratified Cross-Validation on training data to select the optimal algorithm before final testing.

4. Interactive Dashboard

Flask web interface collects user applications, infers predictions from all 3 models simultaneously, and logs history to SQLite.
